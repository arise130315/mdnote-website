# mdnote.blinkwork.cn 官网

MDNote（Mac 原生 Markdown 管理器）官方网站的线上文件。线上地址：https://mdnote.blinkwork.cn

> 纯静态站，本仓库是构建产物的存档；源码在本机工程里，由 `npm run build` 生成后同步过来。直接用浏览器打开 `index.html` 即可预览。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 首页 |
| `download/` | 下载页 |
| `privacy/`、`terms/` | 隐私政策、用户协议 |
| `404.html` | 找不到页面 |
| `styles.css`、`app.js` | 样式与交互 |
| `assets/` | 图标与界面截图 |

## 部署

把上述文件原样放到 Web 服务器的站点目录即可，无需编译。
